### Date: 23-Jan-2026 – CSV Data Handling with Java I/O  
- Studied CSV fundamentals, structure, and real-world use cases.
- Read CSV files using:
  - `BufferedReader` (manual parsing)
  - OpenCSV (`CSVReader`)
- Wrote CSV data using:
  - `BufferedWriter`
  - OpenCSV (`CSVWriter`)
- Parsed rows using `String.split()` and mapped records into Java objects with `CsvToBean`.
- Implemented data validation:
  - Numeric field checks
  - Regex-based column validation.
- Practiced record filtering, searching, updating, sorting, and merging CSV files.
- Implemented efficient processing for large CSV files using chunked reads.
- Generated reports and export files from structured datasets.
